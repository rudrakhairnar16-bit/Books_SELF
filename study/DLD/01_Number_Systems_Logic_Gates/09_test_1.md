## Part A — MCQ (1 mark each, 10 marks)
1. Which gate gives output 1 only when both inputs are 0? (a) NAND (b) NOR (c) XOR (d) AND
2. IC 7486 contains: (a) NAND (b) NOR (c) XOR (d) OR gates
3. (A + B)' equals: (a) A' + B' (b) A'B' (c) AB (d) A + B
4. A + A'B = (a) A (b) B (c) A + B (d) AB
5. (2671)₈ in decimal = (a) 1465 (b) 1456 (c) 1645 (d) 1546
6. 2's complement of 10101010 = (a) 01010101 (b) 01010110 (c) 10101011 (d) 01010111
7. Range of 8-bit 2's complement: (a) 0–255 (b) −127…127 (c) −128…127 (d) −128…128
8. Which BCD code is invalid? (a) 0101 (b) 1001 (c) 1100 (d) 0000
9. Gray code of 1001 = (a) 1101 (b) 1110 (c) 1011 (d) 1100
10. Minimum parity bits for 4 data bits (Hamming): (a) 2 (b) 3 (c) 4 (d) 1

## Part B — Short (3 marks each, 9 marks)
11. Convert (172.878)₁₀ to octal (4 fraction digits).
12. Using 2's complement, compute 100010 − 100110.
13. Draw OR gate using only NAND gates and prove it with Boolean algebra.

## Part C — Long (6 marks)
