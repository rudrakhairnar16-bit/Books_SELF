New node before a given node in a singly linked list  
 
Step 1: Check for Overflow  
​
IF AVAIL = NULL  
Write "OVERFLOW"  
Go to  
Step 12 [END OF IF]  
Step 2: Allocate New Node  
​
SET NEW_NODE = AVAIL  
Step 3: Update AVAIL  
​
SET AVAIL = AVAIL -> NEXT  
Step 4: Assign Data to New Node  
​
SET NEW_NODE -> DATA = VAL  
Step 5: Initialize Pointers for Traversal  
​
SET PTR = START  
Step 6: Set PREPTR = PTR  
​
SET PREPTR = PTR  (Initializes a pointer PREPTR to keep track of the previous node 
during traversal. ) 
Step 7: Loop Until Target Node is Found  
​
Repeat Steps 8 and 9 while PREPTR -> DATA != NUM (Continues traversing the list 
until PREPTR holds the value NUM. ) 
Step 8: Move PREPTR to Current PTR  
​
SET PREPTR = PTR (Saves the current node as the previous node before moving 
forward. ) 
Step 9: Move PTR to Next Node  
​
SET PTR = PTR -> NEXT (Advances the pointer to the next node in the list. ) 
Step 10: Link PREPTR to NEW_NODE  
​
SET PREPTR -> NEXT = NEW_NODE (Inserts NEW_NODE after PREPTR. ) 
Step 11: Link NEW_NODE to PTR  
​
SET NEW_NODE -> NEXT = PTR (Completes the link by connecting NEW_NODE 
to the current node (PTR). ) 
Step 12: EXIT

deleting a node from the beginning of a singly linked list  
 
Step 1: Check for Underflow (Empty List)  
IF START = NULL  
Write UNDERFLOW  
Go to Step 5  
[END OF IF]  
 
Step 2: Store the First Node in PTR  
SET PTR = START  
 
Step 3: Move START to the Next Node  
SET START = START -> NEXT  
 
Step 4: Free the Removed Node  
FREE PTR  
 
Step 5: EXIT  
 
 
Delete the last node from a singly linked list.  
 
Step 1: Check for Underflow (Empty List)  
IF START = NULL  
Write UNDERFLOW  
Go to Step 5  
[END OF IF]  
 
Step 2: Store the First Node in PTR  
SET PTR = START  
 
Step 3: Traverse the List Until Last Node  
Repeat Steps 4 and 5 while PTR -> NEXT != NULL  
 
Step 4: Update PREPTR  
SET PREPTR = PTR (Stores the current node before moving PTR forward. ) 
 
Step 5: Move PTR to the Next Node  
SET PTR = PTR -> NEXT  

===== PAGE 4 =====
 
Step 6: Unlink the Last Node  
SET PREPTR -> NEXT = NULL (Disconnects the last node from the list ) 
 
Step 7: Free the Last Node  
FREE PTR  
 
Step 5: EXIT 
 
 
Add new node at the start of a circular singly linked list  
 
 
Step 1: Check for Overflow

[END OF IF]  
 
Step 2: Allocate a New Node  
SET NEW_NODE = AVAIL  

===== PAGE 5 =====
Step 3: Update AVAIL 
SET AVAIL = AVAIL -> NEXT 
 
Step 4: Store the Data 
SET NEW_NODE -> DATA = VAL 
 
Step 5: Start Traversal 
SET PTR = START 
 
Step 6: Traverse Until Last Node 
Repeat Step 7 while PTR -> NEXT != START (Loop until PTR points to the last node in 
the circular list. ) 
 
Step 7: Move Pointer Forward 
PTR = PTR -> NEXT 
 
Step 8: Point New Node to Old Start 
SET NEW_NODE -> NEXT = START(The new node’s NEXT should point to the old 
START. ) 
 
Step 9: Update Last Node to Point to New Node 
SET PTR -> NEXT = NEW_NODE (The last node (pointed by PTR) now points to the new 
node. ) 
 
Step 10: Update START 
SET START = NEW_NODE 
 
Step 11: EXIT
