Data Structure Basic Concepts
•
Data Structure is a systematic way to organize data in order to use it efficiently.
• Data structure is an arrangement of data in computer's memory in such a way that it 
could make the data quickly available to the processor for required calculations.
Data Structure mainly specifies the following four things :
• Organization of Data
• Accessing of Methods
• Degree of Associativity
• Processing alternatives for information

Primitive data structures
Primitive data structures are basic structure and directly operated by machine instruction.  
Example : integer, float, character, pointer, etc.
•Integer : it is a data type which allows values without fraction part. Ex. 10.
•Float : it is a data type which storing values with fraction part. Ex. 10.25.
•Character : it is a data type which is used for storing character value. Ex. A.
•Pointer : It is a variable that holds memory address of another variable. Ex. *p.

===== PAGE 5 =====
Primitive data structures
•Non – primitive data structure are more complicated data structure and they are derived from 
primitive data  structures.
•They emphasis on grouping of same or different data items with relationship between each 
item.
•Example : Array, List and File.
– Array : An array is a fixed-size sequential collection of elements which have same data 
type.
– List : An ordered set containing variable number of elements is called as lists.
– File : A file is a collection of logically related information.
•Non – primitive Data Structures are further divided into Linear and Non – Linear Data 
Structures.

===== PAGE 6 =====
Linear data structures
•A data structure is said to be linear, if its elements are connected in linear fashion by 
means of logically or in  sequence memory locations.
•Example : Stack and Queue
– Stack : Stack is also called as LIFO(Last In First Out) data structure. Insertion operation 
is known as “PUSH” Operation and Deletion
Operation is known as “POP” Operation.
– Queue : Queue is also called as FIFO(First In First Out) data structure. End at which 
insertion occurs is known as “REAR” and end at  which deletion occurs is known as 
“FRONT”.

Introduction to Algorithms
•Algorithm is a Step – by – Step Procedure.
•It defines a set of instructions to be executed in a certain order to get the desired output.
•Data structures are implemented using algorithms.
•An algorithm explicitly states how the data will be manipulated.

===== PAGE 9 =====
Key Features of Algorithms
Unambiguous : Algorithm should be clear and unambiguous. Each of its phases, input and 
output should be  clear and must lead to only one meaning.
Input : An algorithm should have 0 or more well – defined inputs.
Output : An algorithm should have 1 or more well-defined outputs, and should match the 
desired output.
Finiteness – Algorithms must terminate after a number of steps.
Feasibility – Should be feasible with the available resources.
Independent – An algorithm should have step-by-step directions, which should be of any 
programming code.

===== PAGE 10 =====
Time and space analysis of algorithms
– Sometimes, there are more than one way to solve a problem. 
– We need to learn how to compare the performance of different algorithms and 
choose the best one to solve a particular problem. 
– While analyzing an algorithm, we mostly consider time complexity and space 
complexity.
– Time complexity of an algorithm quantifies the amount of time taken by an 
algorithm to run as a function of the length of the input.
– Space complexity of an algorithm quantifies the amount of space or memory taken 
by an algorithm to run as a function of the length of the input.
– Time & space complexity depends on lots of things like hardware, operating 
system, processors, etc. 
– However, we don't consider any of these factors while analyzing the algorithm. We 
will only consider the execution time of an algorithm.

===== PAGE 11 =====
Analysis Terms of Algorithm
•Time Complexity
Time Complexity of an algorithm represents the amount of time required by the 
algorithm to run to  completion. Time requirements can be defined as a numerical 
function T(n), where T(n) can be measured as  number of steps, provided each step 
consumes constant time.
•Space Complexity
Space complexity of an algorithm represents the amount of space or memory an 
algorithm takes in  terms of the amount of input to the algorithm.

Binary Search in 
Array
•Binary search is fast search algorithm with run-time complexity of O(log n).
•This search algorithm works on the principle of divide and conquer.
•For this algorithm, the data collection should be in the sorted form.
•Binary search looks for a particular item by comparing the middle most item of the 
collection.  If a match occurs, then the index is returned. If the middle item is greater than 
the item, then  the item is searched in the sub-array to the left of the middle item. 
Otherwise, the item is  searched for in the sub-array to the right of the middle item. This 
process continues on the  sub-array as well until the size of the subarray reduces to zero.

Binary Search Algorithm
Procedure binary_search  A ← sorted array
n ← size of array
x ← value to be searched
Set lowerBound = 1  
Set upperBound = n  
while x not found
if upperBound < lowerBound
EXIT: x does not exists.
set midPoint = lowerBound + ( upperBound - lowerBound ) / 2
if A[midPoint] < x
set lowerBound = midPoint + 1  
if A[midPoint] > x
set upperBound = midPoint - 1  
if A[midPoint] = x
EXIT: x found at location midPoint
end while
end procedure
