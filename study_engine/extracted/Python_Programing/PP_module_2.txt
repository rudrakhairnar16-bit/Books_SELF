1. Introduction to Control Structures 
Control structures determine the flow of execution of a program. Normally, Python executes 
statements one after another (top to bottom). Sometimes we need to: 
●​ Make decisions 
●​ Repeat a task 
●​ Skip certain statements 
●​ Stop execution 
Python provides Control Structures to perform these tasks. 
There are two major types: 
1.​ Decision Making (Conditional Statements) 
2.​ Looping (Iteration) 
2. Conditional Statements 
Conditional statements allow a program to make decisions based on a condition. 
Python uses the following keywords: 
●​ if 
●​ else 
●​ elif 
A condition always evaluates to either: 
●​ True 
●​ False 

===== PAGE 2 =====
A. if Statement 
The if statement executes a block of code only when the condition is True. 
Syntax 
if condition: 
    statement1 
    statement2 
 
Notice the colon (:) after the condition and the indentation. 
Example 1 
age = 20 
 
if age >= 18: 
    print("Eligible for Voting") 
 
Output: 
Eligible for Voting 
 
Example 2 
marks = 85 
 
if marks >= 35: 
    print("Pass") 
 
Output: 
Pass

C. Nested if Statement 
A Nested if means an if statement inside another if statement. 
Useful when multiple conditions must be checked. 
Syntax 
if condition1:

        statements 
 
Example

    if citizen: 
        print("Eligible to Vote") 
 
Output: 
Eligible to Vote 
 
Example

    if marks >= 75: 
        print("Distinction")

Example 6: Prime Number Check 
num = int(input("Enter a number: ")) 
 
if num <= 1: 
    print("Not Prime") 
else: 
    for i in range(2, int(num ** 0.5) + 1): 
        if num % i == 0: 
            print("Not Prime") 
            break 
    else: 
        print("Prime")

What to use when :  
●​ Indentation is mandatory in Python; it defines the scope of blocks such as if, for, 
and while. 
●​ Choose a for loop when the number of iterations is known, and a while loop when 
repetition depends on a condition. 
●​ Use break to terminate a loop early, continue to skip the rest of the current iteration, 
and pass as a placeholder when a statement is syntactically required. 
●​ Begin solving programming problems by writing the algorithm or flow of logic before 
translating it into Python code.
