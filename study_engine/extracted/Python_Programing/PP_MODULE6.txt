1. Introduction to Python Libraries 
 
What is a Python library? 
 
A Python library is a collection of pre-written code, functions, and 
modules that can be used to perform specific tasks without writing 
everything from scratch. 
 
Advantages of Python libraries: 
● Save development time. 
● Reduce code complexity. 
● Improve code reusability. 
● Provide specialized tools for data analysis, visualization, and 
application development.

5. Object-Oriented Programming (OOP) 
 
5.1 Definition 
 
Object-Oriented Programming is a programming approach that 
organizes code using classes and objects. It helps make programs 
reusable, modular, and easier to maintain. 
 
5.2 Class and object 
● Class: A blueprint or template used to create objects. 
● Object: An instance of a class containing data and behavior. 
 
Example: 
 
python 
class Student: 
    def display(self): 
        print("Hello, Student!") 
 
s1 = Student() 
 
s1.display() 
 
Output: 
 
text 
 
Hello, Student! 
 
Here, Student is the class and s1 is an object. 

===== PAGE 14 =====
 
5.3 Constructor 
 
A constructor initializes an object's attributes when an object is 
created. In Python, __init__() is commonly used for this purpose. 
 
python 
class Student: 
    def __init__(self, name, marks): 
        self.name = name 
        self.marks = marks 
 
    def display(self): 
        print(self.name, self.marks) 
 
s1 = Student("Amit", 85) 
 
s1.display() 
 
Output: 
 
text 
 
Amit 85 
 
Important terms: 
● __init__(): Initialization method. 
● self: Refers to the current instance of the class. 
● self.name: An instance attribute. 
● Student(...): Creates an object and initializes its attributes. 
 
5.4 Types of variables in a class 
 
python 
class Student: 
    school = "ABC School"  # Class variable 
 
    def __init__(self, name): 
 
        self.name = name   # Instance variable 
● Class variable: Shared by instances unless overridden. 

===== PAGE 15 =====
● Instance variable: Belongs to an individual object. 
 
5.5 Four major OOP concepts 
 
 
 
1. Encapsulation 
 
Combining data and methods within a class and controlling access 
to internal details. 
 
Example: A bank account class that provides methods for deposits 
and withdrawals. 

===== PAGE 16 =====
 
 
 
2. Abstraction 
 
Hiding unnecessary implementation details and exposing only the 
essential features. 
 
Example: Driving a car without knowing the internal workings of 
its engine. 

===== PAGE 17 =====
 
 
 
3. Inheritance 
 
Creating a new class from an existing class to reuse or extend its 
features. 
 
Example: A Dog class inherits common features from an Animal 
class. 

===== PAGE 18 =====
 
 
 
4. Polymorphism 
 
The same interface or method name can produce different behavior 
depending on the object. 
 
Example: Different animal objects implement sound() differently. 
 
5.6 Inheritance 
 
Inheritance allows a child class to reuse and extend a parent class. 
 
python 
class Animal: 
    def eat(self): 
        print("Animal eats") 

===== PAGE 19 =====
 
class Dog(Animal): 
    def bark(self): 
        print("Dog barks") 
 
d = Dog() 
d.eat() 
 
d.bark() 
 
Output: 
 
text 
Animal eats 
 
Dog barks 
 
Types of inheritance: 
● Single inheritance: One child inherits from one parent. 
● Multiple inheritance: One child inherits from multiple parents. 
● Multilevel inheritance: A class inherits from a derived class. 
● Hierarchical inheritance: Multiple child classes inherit from 
one parent. 
● Hybrid inheritance: A combination of inheritance types. 
 
5.7 Method overriding and polymorphism 
 
Method overriding occurs when a child class provides its own 
implementation of a method inherited from the parent class. 
 
python 
class Animal: 
    def sound(self): 
        print("Animal makes a sound") 
 
class Dog(Animal): 
    def sound(self): 
        print("Dog barks") 

===== PAGE 20 =====
 
class Cat(Animal): 
    def sound(self): 
        print("Cat meows") 
 
for animal in [Dog(), Cat()]: 
 
    animal.sound() 
 
Output: 
 
text 
Dog barks 
 
Cat meows 
 
The same method, sound(), behaves differently for different objects. 
This is an example of runtime polymorphism. 
 
5.8 Method overloading in Python 
 
Traditional method overloading means defining multiple methods 
with the same name but different parameter lists. Python does not 
support this form of overloading directly in the same way as 
languages such as Java. 
 
Similar behavior can be achieved with default arguments: 
 
python 
class Calculator: 
    def add(self, a, b=0, c=0): 
        return a + b + c 
 
obj = Calculator() 
 
print(obj.add(5))       # 5 
print(obj.add(5, 3))    # 8 
 
print(obj.add(5, 3, 2)) # 10

6.3 Geometry managers 
 
Tkinter provides three main geometry managers: 
● pack(): Arranges widgets in blocks. 
● grid(): Arranges widgets in rows and columns. 
● place(): Positions widgets using coordinates. 
 
6.4 Basic Tkinter window 
 
python

root.title("My First App") 
root.geometry("300x200") 
 
label = tk.Label(root, text="Welcome to Python!") 

===== PAGE 24 =====

button = tk.Button(root, text="Click Me") 
button.pack() 
 
 
root.mainloop() 
 
Explanation: 
● tk.Tk() creates the main window. 
● title() sets the window title. 
● geometry() sets the initial window dimensions. 
● Label() creates a text label. 
● Button() creates a clickable button. 
● pack() places widgets in the window. 
● mainloop() starts the GUI event loop. 
 
6.5 Tkinter button event handling 
 
A button can call a function when clicked. 
 
python 
import tkinter as tk 
 
def greet(): 
    label.config(text="Hello, Welcome!") 
 
root = tk.Tk() 
root.title("Greeting App") 
 
label = tk.Label(root, text="Click the button") 
label.pack(pady=10) 
 
button = tk.Button(root, text="Greet", command=greet) 
button.pack() 

===== PAGE 25 =====
 
 
root.mainloop() 
 
Here, command=greet connects the button to the function. Do not 
write command=greet() because that would call the function 
immediately during widget creation. 
 
7. Simple Applications Using Tkinter 
 
Application 1: Addition calculator 
 
This program accepts two numbers and displays their sum. 
 
python 
 
import tkinter as tk 
 
def add_numbers(): 
    try: 
        a = float(entry1.get()) 
        b = float(entry2.get()) 
        result.config(text=f"Sum = {a + b:g}") 
    except ValueError: 
        result.config(text="Enter valid numbers") 
 
root = tk.Tk() 
root.title("Addition Calculator") 
root.geometry("300x220") 
 
tk.Label(root, text="First number").pack() 
entry1 = tk.Entry(root) 
entry1.pack() 
 
tk.Label(root, text="Second number").pack() 
entry2 = tk.Entry(root) 

===== PAGE 26 =====
entry2.pack() 
 
tk.Button(root, text="Add", command=add_numbers).pack(pady=10) 
 
result = tk.Label(root, text="Sum = ") 
result.pack() 
 
root.mainloop() 
 
 
 
Working: 
● Entry.get() reads the entered text. 
● float() converts the input into a number. 
● The add_numbers() function calculates the sum. 
● config() updates the result label. 
● try-except handles invalid numerical input.
