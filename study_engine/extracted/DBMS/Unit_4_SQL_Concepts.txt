DDL, or Data Definition Language, is a subset of SQL (Structured Query Language) used for 
defining and managing database structures. DDL commands allow you to create, modify, and 
delete database objects such as tables, indexes, and schemas. Here are some common DDL 
commands:

• CREATE: Used to create new database objects.
□CREATE TABLE employees (id INT PRIMARY KEY, name VARCHAR(100), hiredate

===== PAGE 9 =====
DML COMMANDS AND IT’S SYNTAX
• INSERT: Adds new rows to a table.
□INSERT INTO employees (id, name, hire_date) VALUES (1, 'Alice', '2024-01-15’);
• UPDATE: Modifies existing data in a table.
□UPDATE employees SET salary = 75000 WHERE id = 1;
• DELETE: Removes rows from a table.
□DELETE FROM employees WHERE id = 1;
• SELECT: Retrieves data from one or more tables.
□SELECT name, hire_date FROM employees WHERE salary > 60000;

DCL(Data Control Language)
• DCL, or Data Control Language, is a subset of SQL used to control access to data in a database. 
DCL commands are primarily concerned with permissions and access rights. The two main DCL 
commands are:
• GRANT: Used to give users access privileges to database objects.
□GRANT SELECT, INSERT ON employees TO user1;
• REVOKE: Used to remove access privileges from users.
□REVOKE INSERT ON employees FROM user1;

Functions: Aggregate functions
•Definition:
Aggregate functions in SQL are used to perform calculations on a set of values and 
return a single value. They are commonly used in conjunction with the GROUP BY 
clause to group rows that have the same values in specified columns and then 
perform the aggregation on those groups. Here are some of the most commonly 
used aggregate functions:
1.
COUNT()
2.
SUM()
3.
AVG()
4.
MIN()
5.
MAX()

===== PAGE 31 =====
• COUNT(): Returns the number of rows that match a specified criterion.
• Syntax:
SELECT COUNT(*) AS total_employees FROM employees;
• SUM(): Returns the total sum of a numeric column.
• Syntax:
• SELECT SUM(salary) AS total_salaries FROM employees;
• AVG(): Returns the average value of a numeric column.
• Syntax:
• SELECT AVG(salary) AS average_salary FROM employees;
• MIN(): Returns the smallest value in a set and MAX() returns the largest value in a set.
• Syntax:
• SELECT MIN(salary), MAX(salary) AS lowest_salary FROM employees;

===== PAGE 32 =====
Using Aggregate Functions with GROUP BY
• Aggregate functions are often used with the GROUP BY clause to group rows that 
have the same values in specified columns:
• Example:
• SELECT department_id, COUNT(*) AS employee_count FROM employees GROUP 
BY department_id;

===== PAGE 33 =====
Using Aggregate Functions with HAVING
• You can use the HAVING clause to filter the results of aggregate functions:
• Syntax:
SELECT department_id, AVG(salary) AS average_salary FROM employees GROUP BY
department_id HAVING AVG(salary) > 60000;
EXAMPLE OF MULTIPLE AGGREGATE FUNCTION WITH EXAMPLE:

SET OPERATIONS IN SQL
• Set operations in SQL allow you to combine the results of two or more queries. The 
main set operations include UNION, UNION ALL, INTERSECT, and EXCEPT (or 
MINUS in some systems). Here's a breakdown of each operation:
• 1. UNION:
□The UNION operator combines the results of two or more SELECT statements and 
removes duplicate rows from the result set.
Syntax:
SELECT column1, column2 FROM table1
UNION
SELECT column1, column2 FROM table2;
Example:
SELECT name FROM employees 
UNION
SELECT name FROM contractors;

===== PAGE 43 =====
2. UNION ALL:
SELECT column1, column2 FROM table1
UNION ALL
SELECT column1, column2 FROM table2;
□The UNION ALL operator combines the results of two or more SELECT statements but 
includes all duplicates.
Syntax:
Example:
Syntax:
SELECT column1, column2 FROM table1
INTERSECT
SELECT column1, column2 FROM table2;
3. INTERSECT:
□ The INTERSECT operator returns only the rows that are common to both SELECT 
statements.
Example:
SELECT name FROM employees
UNION ALL
SELECT name FROM contractors;
SELECT name FROM employees
INTERSECT
SELECT name FROM contractors;

===== PAGE 44 =====
• EXCEPT (or MINUS)
□The EXCEPT operator (or MINUS in some SQL dialects like Oracle) returns rows from the 
first SELECT statement that are not present in the second.
Syntax:
SELECT column1, column2 FROM table1 
EXCEPT
SELECT column1, column2 FROM table2;
Example:
SELECT name FROM employees
EXCEPT
SELECT name FROM contractors;

Subqueries and correlated subqueries
• 1. Subqueries:
□A subquery (or inner query) is a query nested inside another SQL query. It can be used in 
various parts of a SQL statement, such as the SELECT, FROM, WHERE, or HAVING clauses. 
Subqueries are typically used to retrieve a set of values to be used by the outer query.
SELECT name, salary 
FROM employees WHERE 
department_id = (
SELECT id
FROM departments
WHERE department_name = 'Sales'
);

===== PAGE 46 =====
• 2. Correlated Subqueries
□A correlated subquery is a type of subquery that references columns from the outer 
query. Unlike a regular subquery, which can be executed independently, a correlated 
subquery is executed repeatedly, once for each row processed by the outer query.
Syntax:
SELECT e.name, e.salary 
FROM employees e 
WHERE e.salary > (
SELECT AVG(salary) 
FROM employees
WHERE department_id = e.department_id
);

Use of group by, having, order by
• The GROUP BY, HAVING, and ORDER BY clauses in SQL are essential for organizing 
and summarizing data in queries. Here’s an overview of each clause and how they can be 
used together.
• 1. GROUP BY:
□The GROUP BY clause is used to group rows that have the same values in specified 
columns into summary rows. It is often used with aggregate functions (like COUNT(), 
SUM(), AVG(), etc.) to perform calculations on each group.
Example:
SELECT department_id, COUNT(*) AS employee_count 
FROM employees
GROUP BY department_id;
▪This query counts the number of employees in each department by grouping the results 
based on department_id.

===== PAGE 48 =====
• 2. HAVING:
□The HAVING clause is used to filter records after the aggregation has taken place. While the 
WHERE  clause  filters  records  before  aggregation,  HAVING  is  specifically  for  filtering 
grouped records.
Syntax:
SELECT department_id, AVG(salary) AS average_salary 
FROM employees
GROUP BY department_id
HAVING AVG(salary) > 60000;
▪In this example, the query retrieves departments with an average salary greater than 60,000 
after calculating the average salary for each department.

===== PAGE 49 =====
• 3. ORDER BY:
□The ORDER BY clause is used to sort the result set of a query by one or more columns. By 
default, the sorting is in ascending order, but you can specify descending order using the 
DESC keyword.
Syntax:
SELECT name, salary 
FROM employees 
ORDER BY salary DESC;
❑Using GROUP BY, HAVING, and ORDER BY Together.
Example:
SELECT department_id, COUNT(*) AS employee_count, AVG(salary) AS 
average_salary FROM employees
GROUP BY department_id
HAVING AVG(salary) > 60000
ORDER BY employee_count DESC;
